HUNHO Voice Calendar

HUNHO Voice Calendar is a personal voice-powered calendar assistant designed for Amazfit smartwatches.

Features

The application allows its authorized user to record voice commands on a smartwatch, convert speech into calendar event details, and create events in Google Calendar.

Google Calendar Integration

Google Calendar access is used solely to create calendar events requested by the authorized user.
