Privacy Policy

Application: HUNHO Voice Calendar

Last updated: October 12, 2026

1. Overview

HUNHO Voice Calendar is a personal application designed to create Google Calendar events using voice commands recorded on an Amazfit smartwatch.

2. Information Processed

The application may process the following information:

  • Voice recordings submitted by the authorized user.
  • Speech transcription results.
  • Calendar event details, including titles, dates and times.
  • Google OAuth authorization credentials required to access Google Calendar.

3. How Information Is Used

Voice recordings are processed to recognize spoken commands and extract calendar event information.

Google Calendar access is used to create calendar events requested by the authorized user.

4. Third-Party Services

The application uses the following services:

  • Google Calendar API: to create calendar events.
  • OpenAI API: to process voice recordings and assist with speech recognition and interpretation.
  • Google Cloud Run: to operate the application server.

5. Data Storage and Retention

Audio files are temporarily stored on the application server during processing. The application attempts to delete these temporary files after processing is completed.

Speech transcription results and related diagnostic information may be recorded in server logs for troubleshooting. Such logs may be retained according to the configured Google Cloud logging retention settings.

Data processed by third-party services may be subject to their respective data processing and retention policies.

6. Google Calendar Data

The application requests Google Calendar permissions to create events initiated by the authorized user.

Google Calendar information is not sold or used for advertising purposes.

7. Security

The application uses OAuth 2.0 authorization for Google Calendar access. Authentication credentials are maintained in the server environment and are not published on this website.

8. User Control and Deletion

The authorized user can revoke Google account access through Google Account security settings.

Calendar events created by the application can be managed or deleted directly in Google Calendar.

Requests concerning application data or diagnostic logs may be directed to the developer using the contact information below.
